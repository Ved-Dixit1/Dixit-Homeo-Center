# Dixit Homeopathic Clinic (Dixit Homeo Centre)

A premium, highly interactive, and responsive single-page healthcare landing website designed for **Dixit Homeopathic Clinic** in Balaghat. Built using modern semantic HTML5, clean vanilla CSS variables, and dynamic vanilla JavaScript.

## ✨ Features
1. **🌿 Healing Visual Identity**: Designed using a custom variables-based palette (Teals & Emeralds) representing safe, holistic, and natural homeopathic care.
2. **🌓 Light & Dark Theme Support**: High-fidelity dark and light themes with persistence saved locally to `localStorage` and fallback support detecting native operating system configurations.
3. **👨‍⚕️ Doctor Showcase**: Dedicated About section highlighting Dr. Dixit's expert credentials, core healing philosophies, and an elegant circular portrait frame.
4. **📞 Auto-Call Appointment Booking**: A fully validated patient scheduling preference form. On successful submission, it launches a custom booking summary modal and automatically initiates a direct verification call to the clinic line at **9893457822**.
5. **🖼️ Authentic Clinic Gallery**: Features real, original photos extracted directly from the official clinic listing showcasing the entrance, signboards, and interiors.
6. **💬 Testimonials Section**: Interactive patient cards capturing ratings and real recovery success stories (Eczema, chronic hyperacidity, child bronchitis).
7. **❓ Collapsible FAQ Accordion**: Fully animated accordions answering general patient queries regarding homeopathic safeness, durations, and conventional interactions.

---

## 🛠️ Technology Stack
* **Markup**: Semantic HTML5 (header, nav, main, section, article, footer)
* **Styling**: Vanilla CSS3 (Custom Variables, Grid, Flexbox, Glassmorphism `backdrop-filter`, Scroll transitions)
* **Interactivity**: Vanilla JavaScript ES6 (Intersection Observer, LocalStorage, viewport-active link tracking)

## 🚀 Running Locally

To run the site locally, clone the repository and launch a static server.

### Option A: VS Code Live Server
1. Open the project folder in VS Code.
2. Click **Go Live** at the bottom-right status bar.

### Option B: Command Line (Python)
Run the following command inside the project directory:
```bash
python3 -m http.server 8080
```
Then visit **[http://localhost:8080](http://localhost:8080)** in your browser.
